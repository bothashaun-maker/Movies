# JesusJuiceProductions Image Studio

[Open Image Studio v6](Image_Studio_Kaggle_v6.ipynb) · [Production playbook](notebooks/image_studio/JJP_PLAYBOOK.md) · [Model packs](Image_Studio_Model_Packs.ipynb) · [Validation](notebooks/image_studio/JJP_VALIDATION.md)

One Kaggle/ComfyUI studio for image creation, restyling, inpainting, face swap and upscaling. The JJP production layer applies the supplied launch plan's cinematic worlds, approved-cast library, episode briefs and consistent branded export. All earlier general workflows remain available.

Import v6 into Kaggle, attach existing model packs, enable Internet/T4, and run its single startup cell. Select a workflow and press Run; startup never generates automatically. JJP adds no new model weights. Keep approved-cast photos and finished outputs private and saved; model packs alone do not preserve them.

Eight editable episode presets and custom wing controls are included. Cast references start empty and require your explicit approval. Face-swap weights remain non-commercial research only; the creative plan does not alter model licenses. Full live Kaggle execution and user-photo likeness remain unverified; see the validation page for completed local checks.
