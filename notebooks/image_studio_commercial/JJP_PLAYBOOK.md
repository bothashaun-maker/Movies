# JesusJuiceProductions commercial image playbook

Use the Commercial v7 notebook and two commercial packs for new music-video stills. Keep v1–v6 only as historical references. Their InsightFace path is unsuitable for this commercial profile. Read LICENSE_AUDIT.md for the full component review and MIGRATION.md before redoing images.

Start with a shot brief: select one of the eight supplied episode worlds or Custom, choose format, describe the scene, select cast and enter the precise scripture reference you intend. Custom world, palette and wing remain editable. The supplied creative direction stays cinematic and realistic; antagonists remain non-human or faceless, and the Seeker remains faceless. No scripture quotation is fabricated. Verify references and any user-supplied text before publication.

Create scene candidates with the four-step Klein 4B Create workflow. Approve a clear original identity photo in Approve Cast only after checking consent, rights, appearance and suitability; set approved=true explicitly. Save the private PNG and cast record together. Existing cast records can be loaded but an approved flag is not proof their image was created with commercially permitted models. Audit their provenance first.

For dedicated head/identity replacement, start with **BFS Head Swap 4B** (or Approved Cast BFS Head Swap 4B). Target scene is Picture 1, identity is Picture 2; native model-only LoRA strength starts at 1.0. It can replace hair/head, so use Masked Edit or generic Identity Edit when only a smaller region should change.

Other face methods: **Identity Edit** uses the clean scene as image 1 and your identity as image 2. Describe which person changes and what stays fixed. Approved Cast Identity Edit supplies your saved reference and prefix. Approved Duet uses Lead One and Lead Two records and three native reference latents. Check the two identities separately; no automated identity score or fidelity guarantee is supplied. **Mesh Face Composite** uses similar-pose source/target photographs, with selectable zero-based face indices left to right. It is pixel warping/blending, not a trained identity-swap network. Save and inspect the report, edges, eyes, skin, jaw, pose and lighting.

For local revisions use Masked Edit: paint a replacement mask in LoadImage MaskEditor. The whole candidate is reference-generated, then only the masked region/feather is pasted into the original. For broader changes use Reference Edit. For a creative enhancement, use Reference Edit with a low-change detail instruction, then Real-ESRGAN or SeedVR2; generative revisions can change faces and text. This replaces the old SDXL creative/detail route without loading Juggernaut or UltimateSDUpscale. It does not reproduce its tile sampler exactly.

Upscale after identity approval. Real-ESRGAN 2×/4× is the simpler option. SeedVR2 restoration may invent detail; begin at source sizes around 1024 pixels or smaller, inspect eyes and texture, and compare against your approved reference. Save the result and feed it to **Delivery Export** for deterministic branding. Generation workflows already export a master, delivery PNG and episode.json. The master preserves the image entering export: if that image has already been swapped it is not a clean pre-swap original. Delivery formatting uses padding/Lanczos and does not count as neural upscaling.

Keep each shot's original reference, clean target, accepted graph/prompt/seed, model provenance, licenses and delivered still. Review likeness, non-human character rules, title readability, scripture, unwanted artifacts and synthetic-content disclosure where applicable. No automated export grants publication approval. For actual video, these are still-image assets for your music-video pipeline; temporal identity tracking/video compositing is outside this notebook.
